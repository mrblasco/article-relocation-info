*An Experiment on How Communication Shapes European Views of Fairness in the EU Asylum Relocation System*

Andrea Blasco, Begoña Cabeza Martínez, Rossella Icardi, Michal Krawczyk

Pre-registration: [AEARCTR-0014194](https://www.socialscienceregistry.org/trials/14194)

## Project layout

```
manuscript/      Rmd source files (main.Rmd + chapter files)
scripts/         Analysis pipeline (run in order: 01 → 33)
R/               Shared R utility functions
data/processed/  Cleaned survey data (gitignored; regenerated by scripts/01)
results/         Tables and models produced by scripts (gitignored)
submissions/     Tracked journal submission snapshots (.tex + diffs)
docs/            Working render output — current PDF/HTML (gitignored)
assets/ → see manuscript/assets/
```

## Dependencies

- **R** (≥ 4.2) with packages: `rmarkdown`, `bookdown`, `knitr`, `dplyr`, `tidyr`, `ggplot2`, `ggtext`, `patchwork`, `kableExtra`, `flextable`, `mlogit`
- **LaTeX** with `xelatex` and Times New Roman font
- **latexdiff** (for revision diff PDFs)
- **`fairMigrate`** R package — contains the raw survey data (install separately)

## Reproduce the analysis

```bash
# 1. Prepare data and run all analysis scripts
make analysis

# 2. Render the manuscript to docs/report.pdf
make pdf

# 3. Or do both in one step
make all
```

## Journal submission workflow

### Save a submission snapshot

After building the PDF, save the compiled `.tex` as a tracked snapshot:

```bash
make submit JOURNAL=jebo REV=rev2
# creates submissions/jebo/rev2/manuscript.tex
git add submissions/jebo/rev2/manuscript.tex
git commit -m "snapshot jebo rev2"
```

### Generate a diff between revisions

Produces a `diff.tex` with additions/deletions marked for the journal:

```bash
make diff JOURNAL=jebo FROM=rev1 TO=rev2
# creates submissions/jebo/rev2/diff.tex

make diff-pdf JOURNAL=jebo REV=rev2
# compiles to submissions/jebo/rev2/diff.pdf
git add submissions/jebo/rev2/diff.tex
git commit -m "diff jebo rev1→rev2"
```

Only `.tex` files are tracked in git; `.pdf` files are gitignored and regenerated on demand.
